# PDF to MS Word Automation

This project automates the conversion of a structured PDF form into a Microsoft Word document using Python.

## Overview

The goal of this project was to programmatically recreate a PDF (a legal mediation application form) into a Word document with preserved structure, headings, and table-based formatting.

## Tech Stack

- Python 3
- python-docx

## Features

- Uses `python-docx` to generate a Word document.
- Table-based layout to approximate the PDF structure.
- Fully automated with placeholders for client and party details.
